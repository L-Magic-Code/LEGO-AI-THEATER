Actions explaination:
'move': Moves an actor to a specifies place. Arguments can be 'offstage', 'stage-left', 'stage-center', or 'stage-right'
'say': Makes an actor say something. Argument is one string and can be up to 30 words. Make sure that the argument is wht the actor is saying, not an action. So do not do something like "<actor> say Actor picks up a banana", because that is not what the actor is accually saying.
'spin': Turns the turning object 180 degrees, and can be used to expose whatever is behind it. This has no arguments amd can only be used for the turning object.
'lower': Lowers the flying object, exposing it. This has no arguments and can only be used for the flying object.
'raise': Raises the flying object, hiding it. This has no arguments and can only be used for the flying object.
'wait': Pauses for a certain amount of time. Arguments may be a float (as a string) of how many seconds to wait.
'play_effect': Plays a sound effect. Arguments are the sound effect to play, and wether to loop or not (loop may be True or False): "play_effect <effect> <loop>"
'stop_effect': Plays a sound effect. Arguments are the sound effect to stop: "stop_effect <effect>"


There is also the action: "music change <song>" with <song> being the song to start playing
